================================================================================
                     UDYAM SAARTHI - HOW TO RUN THE PROJECT
================================================================================

PREREQUISITES:
  - Python 3.11+ installed
  - Node.js (v18+) and npm installed

--------------------------------------------------------------------------------
METHOD 1: RUN BACKEND AND FRONTEND IN 2 SEPARATE TERMINALS (RECOMMENDED)
--------------------------------------------------------------------------------

TERMINAL 1 (FastAPI Backend):
  1. Open terminal and navigate to the project directory:
     cd SIH_2026

  2. Enter the backend directory:
     cd backend

  3. Install backend dependencies (required only once on first setup):
     pip install -r requirements.txt

  4. Start the FastAPI backend server:
     python -m uvicorn app.main:app --reload --port 8000

  -> Backend is live at:   http://localhost:8000
  -> Swagger API Docs at:  http://localhost:8000/docs
  -> Health Check URL:     http://localhost:8000/api/health


TERMINAL 2 (React + Vite Frontend):
  1. Open a new terminal window and navigate to the project directory:
     cd SIH_2026

  2. Enter the frontend directory:
     cd frontend

  3. Install frontend dependencies (required only once on first setup):
     npm install

  4. Start the Vite dev server:
     npm run dev

  -> Frontend Web App is live at:  http://localhost:5173


--------------------------------------------------------------------------------
METHOD 2: RUN FROM PROJECT ROOT FOLDER
--------------------------------------------------------------------------------

From the root project directory (where root package.json is located):

TERMINAL 1 (Backend):
  npm run dev:backend

TERMINAL 2 (Frontend):
  npm run dev:frontend


--------------------------------------------------------------------------------
HOW TO RUN AUTOMATED TEST SUITE (45 TESTS)
--------------------------------------------------------------------------------

From the project root folder:
  python -m pytest tests/ -v


--------------------------------------------------------------------------------
COMMON TROUBLESHOOTING
--------------------------------------------------------------------------------

1. Error: "'vite' is not recognized as an internal or external command"
   Fix: You need to run `npm install` inside the `frontend` directory first:
        cd frontend
        npm install

2. Error: "Missing script: 'dev:frontend'"
   Fix: That script only exists in the ROOT folder package.json.
        If you are already inside the `frontend` directory, run:
        npm run dev

3. Port 8000 already in use:
   Check running python processes and stop the existing process:
   In Windows PowerShell:
     Get-Process -Id (Get-NetTCPConnection -LocalPort 8000).OwningProcess | Stop-Process -Force
